# 额度管家规则归档

`quota_guard` 是 AstrBot 插件，依赖 `on_waiting_llm_request` / `on_llm_response`，不直接搬到 DSH。
以下规则需要在模型网关里重建。

## 限额

- 群日限额：1,000,000 token
- 用户日限额：200,000 token
- 用户范围：`global`（跨群 + 私聊合计）
- 重置：每天 00:00
- 豁免用户：主人 QQ
- 超限动作：只提示一次，然后停止回复
- 提示文案：“今天的额度用完了，明天再来吧。”

## 计价

- 输入：1.0
- 缓存输入：0.02
- 输出：4.0
- 峰时倍率：2.0
- 峰时窗口：09:00–12:00、14:00–18:00
- 缓存 token 权重：0.02

## 行为细节

- 私聊也计数/拦截（`apply_private=true`）
- 群未在名单内不计数
- 戳一戳事件优先取原始报文里的 `group_id` / `user_id`
- 机器人自己发的消息不记账
- 预警阈值：80%
- 超限只发一次提示，避免刷屏

## DSH 迁移方式

不搬插件；把以上规则做成网关或 DSH 预算服务的配置项。
网关完成前，AstrBot 侧继续保留 `quota_guard`。
